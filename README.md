# Yves Shabo Nkulu-Ily — Innovation Portfolio

Static portfolio for GitHub Pages or any standard web host.

## Publish on GitHub Pages

1. Create or open a GitHub repository.
2. Copy the contents of this folder into the repository root.
3. Commit and push the files.
4. In **Settings → Pages**, choose **Deploy from a branch**.
5. Select the publishing branch and the `/ (root)` folder.
6. Save. GitHub Pages will publish `index.html` as the site entry point.
